# Quick Start

To try the project, deploy or start the `web/` frontend.

## Deploy with Vercel

Import the repository into Vercel. The root `vercel.json` builds `web/` and deploys `api/proxy.js` as a serverless function.

Requests go through the same-origin `/api/proxy` by default: the serverless function forwards them to your model endpoint, so the browser never touches a third-party origin and CORS stops being an issue. Nothing needs to run locally. Any OpenAI-compatible host is allowed out of the box.

To keep others from using your deployment as a public CORS relay, tighten it with `PROXY_ALLOWED_HOSTS=api.openai.com,your-relay.com` (comma separated, `*.example.com` supported), and optionally `PROXY_TOKEN=xxx` with `?token=xxx` appended to the proxy address in Settings → Request proxy.

To go back to direct browser requests, turn the proxy switch off in Settings → Request proxy.

Vercel Functions cap request and response bodies at 4.5 MB, so uploading large reference images or receiving large base64 payloads can return 413. For those cases, deploy `canvas-proxy` separately on a service without that limit.

## Run locally

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas/web
bun install
bun run dev
```

Open `http://localhost:3000`.

Cross-origin requests are rewritten to the same-origin `/api/proxy?url=<target>` and forwarded (and streamed back) by the local Vite middleware — or by the serverless function once deployed. No extra process is needed and the browser never contacts third-party hosts directly. Switch the mode to Local if you would rather use a standalone proxy process, or turn the switch off to restore direct requests.

### When your network needs a proxy

Forwarding is done by Node's `fetch`, which does **not** read the operating system proxy settings. An endpoint your browser can reach may therefore still time out here:

```json
{"error":"代理请求失败","detail":"UND_ERR_CONNECT_TIMEOUT","target":"https://..."}
```

Point Node at your local proxy client before starting the dev server:

```powershell
$env:NODE_USE_ENV_PROXY="1"
$env:HTTPS_PROXY="http://127.0.0.1:7897"
$env:HTTP_PROXY="http://127.0.0.1:7897"
npm run dev
```

Replace `7897` with your proxy port. If you later shut the proxy client down, clear these variables (`Remove-Item Env:HTTPS_PROXY`), otherwise forwarding keeps dialing a port that no longer listens.

## Run with Docker

```bash
docker build -t infinite-canvas .
docker run --rm -p 3000:3000 infinite-canvas
```

## First-time setup

- Open Settings and enter your `Base URL`, `API Key`, and model names.
- Open `/prompts` to fetch prompt repositories directly from the browser and cache them in IndexedDB.
- Configure WebDAV if you want to synchronize canvases, assets, and generation history across devices.

Canvas projects and My Assets are primarily stored in the browser. The API key is also stored locally and used by the browser to call OpenAI-compatible endpoints directly.
